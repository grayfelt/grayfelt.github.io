# Medieval Portfolio

This project is a personal portfolio website designed to resemble a medieval manuscript. It features a landing page with an introductory section and a blog section where users can scroll through and read various entries. The website includes a gallery page to showcase works and a contact page for users to reach out.

## Project Structure

- **src/assets/fonts**: Contains font files used for styling the website.
- **src/assets/styles**: 
  - `manuscript.css`: Styles designed to give the website a medieval manuscript look.
  - `reset.css`: CSS reset styles for consistent rendering across browsers.
- **src/components**: 
  - `blog-entry.html`: Template for individual blog entries.
  - `footer.html`: HTML structure for the footer.
  - `header.html`: HTML structure for the header, including the title and introductory content.
  - `nav.html`: HTML structure for the navigation bar.
- **src/pages**: 
  - `index.html`: Main landing page styled as a medieval manuscript with a blog section.
  - `gallery.html`: Page showcasing the gallery of works.
  - `contact.html`: Page providing contact information and a form.
- **src/scripts**: 
  - `main.js`: JavaScript code for interactivity on the website.
- **src/content**: 
  - `blog-posts.json`: Contains blog posts in JSON format for dynamic loading.
- **package.json**: Configuration file for npm, listing dependencies and scripts.

## Setup Instructions

1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Install the necessary dependencies using npm:
   ```
   npm install
   ```
4. Open the `src/pages/index.html` file in your browser to view the landing page.

## Purpose

The purpose of this website is to showcase personal works and provide a platform for sharing thoughts and ideas through blog entries, all while maintaining a unique medieval aesthetic.
